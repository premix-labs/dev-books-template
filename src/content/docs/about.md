**Dev Books Template** คือโครงเริ่มต้นสำหรับสร้างหนังสือ Programming ออนไลน์ที่เน้นการนำความรู้ไปใช้ในการทำงานจริง

เนื้อหาภายในเป็นตัวอย่างเท่านั้น คุณสามารถเปลี่ยนชื่อหนังสือ สี เมนู สารบัญ และไฟล์ Markdown หรือ MDX ให้ตรงกับโปรเจกต์จริงได้

## สิ่งที่ Template เตรียมไว้

- หน้าแรกสำหรับแนะนำหนังสือ
- ระบบสารบัญ ค้นหา และ Dark Mode จาก Starlight
- ตัวอย่างบทเรียนพร้อม code block และแบบฝึกหัด
- GitHub Actions สำหรับ deploy ไปยัง GitHub Pages
- Tailwind CSS 4 และฟอนต์ภาษาไทยที่พร้อมปรับแต่ง
