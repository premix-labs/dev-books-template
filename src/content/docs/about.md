**Dev Books** คือพื้นที่สำหรับพัฒนาหนังสือ Programming ออนไลน์ที่เน้นการนำความรู้ไปใช้ในการทำงานจริง

โครงการเริ่มต้นด้วยพื้นที่สำหรับหนังสือ C#, TypeScript และ Python โดยยังสามารถปรับชื่อ ลำดับการเขียน และโครงสร้างเนื้อหาได้ในภายหลัง

## หลักการของหนังสือ

- อธิบายเหตุผลควบคู่กับวิธีเขียนโค้ด
- ใช้ตัวอย่างที่ใกล้กับงานของ Developer
- มีแบบฝึกหัดและโปรเจกต์สำหรับลงมือทำ
- แต่ละเล่มอ่านแยกจากกันได้
