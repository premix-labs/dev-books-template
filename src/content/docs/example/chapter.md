บทนี้แสดงรูปแบบพื้นฐานสำหรับบทเรียน Programming หนึ่งบท เนื้อหาจริงควรเริ่มจากสิ่งที่ผู้อ่านจะทำได้หลังเรียนจบ แล้วค่อยพาไปทีละขั้น

## แนวคิดสำคัญ

ฟังก์ชันช่วยรวมขั้นตอนที่เกี่ยวข้องไว้ด้วยกัน ทำให้เรียกใช้ซ้ำ ทดสอบ และอ่านโค้ดได้ง่ายขึ้น

```ts
export function greet(name: string): string {
  return `สวัสดี, ${name}!`;
}

console.log(greet('Developer'));
```

## อธิบายตัวอย่าง

- `name` คือข้อมูลที่ส่งเข้าสู่ฟังก์ชัน
- `string` ระบุชนิดข้อมูลที่รับเข้าและส่งกลับ
- `return` ส่งผลลัพธ์ให้ส่วนอื่นของโปรแกรมนำไปใช้ต่อ

## ลองทำด้วยตัวเอง

ปรับฟังก์ชัน `greet()` ให้รับเวลาของวัน และแสดงคำทักทายที่แตกต่างกันระหว่างช่วงเช้ากับช่วงเย็น

> เมื่อเขียนหนังสือจริง ควรเพิ่มผลลัพธ์ที่คาดหวัง คำใบ้ และเฉลยแยกไว้ท้ายบท
