ต่อจากบทก่อน เรามีโฟลเดอร์ `greeting` และติดตั้ง TypeScript แล้ว บทนี้จะสร้างฟังก์ชันรับชื่อและคืนข้อความทักทาย โดยแยกการสร้างข้อความออกจากการแสดงผล

## สร้างไฟล์ index.ts

สร้างไฟล์ชื่อ `index.ts` ไว้ระดับเดียวกับ `package.json` แล้วพิมพ์โค้ดนี้:

```ts title="index.ts — สร้างฟังก์ชัน"
export function greet(name: string): string {
  const message = `สวัสดี, ${name}!`;
  return message;
}
```

`function` ประกาศฟังก์ชันชื่อ `greet` ส่วน `name: string` หมายถึงรับพารามิเตอร์ชื่อ `name` ซึ่งต้องเป็นข้อความ และ `: string` หลังวงเล็บกำหนดชนิดของค่าที่ส่งกลับ

`const message` เก็บข้อความที่สร้างขึ้น เครื่องหมายครอบข้อความเป็น backtick ไม่ใช่เครื่องหมายอัญประกาศเดี่ยว ภายใน `${name}` จะนำค่าพารามิเตอร์มาแทรก ส่วน `return` ส่งข้อความกลับไปยังผู้เรียก ฟังก์ชันยังไม่ได้แสดงอะไรบนหน้าจอ

`export` เปิดให้ไฟล์อื่นนำฟังก์ชันนี้ไปใช้ได้ แม้บทนี้ยังเรียกจากไฟล์เดียวกัน ก็ช่วยให้เห็นขอบเขตของฟังก์ชันที่เตรียมใช้ซ้ำ

## เรียกใช้ฟังก์ชัน

เพิ่มบรรทัดเรียกใช้งานใต้ปีกกาปิดของฟังก์ชัน เว้นหนึ่งบรรทัดเพื่อแยกส่วนประกาศกับส่วนทำงาน เมื่อพิมพ์ครบ ไฟล์จะเป็นดังนี้:

```ts title="index.ts — ไฟล์ที่พร้อมรัน"
export function greet(name: string): string {
  const message = `สวัสดี, ${name}!`;
  return message;
}

console.log(greet('Developer'));
```

`greet('Developer')` ส่งชื่อเข้าไปและได้ข้อความกลับมา จากนั้น `console.log` นำข้อความนั้นแสดงใน Terminal บันทึกไฟล์ก่อนทำขั้นตอนถัดไป

## แปลงและรันโปรแกรม

ใน Terminal ที่โฟลเดอร์ `greeting` พิมพ์ทีละคำสั่ง:

```sh
npx tsc index.ts --target ES2022 --module NodeNext --outDir dist --strict
node dist/index.js
```

คำสั่งแรกตรวจชนิดข้อมูลและสร้าง `dist/index.js` โดย `--target ES2022` เลือกรูปแบบ JavaScript, `--module NodeNext` ใช้กติกาโมดูลของ Node.js, `--outDir dist` แยกไฟล์ที่สร้าง และ `--strict` เปิดการตรวจชนิดแบบเข้มงวด หากไม่มีข้อผิดพลาด compiler จะจบโดยไม่มีข้อความ

คำสั่งที่สองให้ Node.js รัน JavaScript ที่สร้างไว้ ควรเห็น:

```text title="ผลลัพธ์"
สวัสดี, Developer!
```

ไฟล์ที่เราแก้คือ `index.ts` ไม่ใช่ `dist/index.js` ทุกครั้งที่แก้ TypeScript ต้องบันทึกและรันคำสั่งแปลงใหม่ก่อนเรียก Node.js

## ถ้าผลลัพธ์ไม่ตรง

หากเห็น `File 'index.ts' not found` ให้ตรวจชื่อไฟล์และตำแหน่ง Terminal หากแสดง `${name}` ตรงตัว ให้เปลี่ยนเครื่องหมายครอบข้อความเป็น backtick และหากผลยังเป็นค่าเดิม ให้บันทึกแล้วแปลงใหม่

ถ้า compiler แจ้งตำแหน่งบรรทัดผิด ให้ตรวจวงเล็บ ปีกกา และเครื่องหมายคำพูดที่บรรทัดนั้น รวมถึงบรรทัดก่อนหน้า อย่าเพิ่งรัน JavaScript เก่าต่อโดยข้ามข้อผิดพลาด

## สรุปสิ่งที่เกิดขึ้น

ข้อมูลไหลจากชื่อที่ส่งเข้า `greet` ไปเป็นข้อความที่ `return` ส่งกลับ แล้วจึงไปแสดงผ่าน `console.log` เราแยกหน้าที่สองอย่างนี้เพื่อให้ฟังก์ชันสร้างข้อความนำไปใช้ต่อได้ โดยไม่ผูกติดกับวิธีแสดงผล
