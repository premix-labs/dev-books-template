หนังสือส่วนนี้เป็นตัวอย่างรูปแบบการสอนสำหรับผู้เขียน ไม่ใช่หลักสูตร TypeScript ฉบับเต็ม เราจะสร้างโปรแกรมทักทายขนาดเล็ก เริ่มจากเตรียมเครื่องมือ พิมพ์ฟังก์ชัน แล้วเพิ่มการตรวจข้อมูล

ทุกขั้นตอนอยู่ในหน้าหนังสือ ไม่มีไฟล์ตัวอย่างให้ดาวน์โหลดและไม่มีแบบฝึกหัดแยก อ่านคำอธิบายก่อนพิมพ์ แล้วเทียบผลลัพธ์ในแต่ละช่วง หากผลไม่ตรง ให้หยุดตรวจจุดนั้นก่อนอ่านต่อ

## เตรียมเครื่องมือ

ติดตั้งโปรแกรมแก้ไขข้อความ เช่น Visual Studio Code และ [Node.js จากเว็บไซต์ทางการ](https://nodejs.org/en/download) ตัวอย่างนี้ใช้ Node.js 24 และ TypeScript 6 ส่วน npm มาพร้อม Node.js

เปิด Terminal ใหม่หลังติดตั้ง บน Windows ใช้ PowerShell บน macOS หรือ Linux ใช้ Terminal จากนั้นพิมพ์ทีละคำสั่ง:

```sh
node --version
npm --version
```

คำสั่งแรกควรขึ้นต้นด้วย `v24.` ส่วนคำสั่งที่สองแสดงหมายเลขเวอร์ชัน npm หมายเลขย่อยอาจต่างจากของผู้เขียนได้ หากขึ้นว่าไม่รู้จักคำสั่ง ให้ปิดและเปิด Terminal ใหม่ แล้วตรวจว่าได้ติดตั้ง Node.js เรียบร้อย

## สร้างพื้นที่ทำงาน

เลือกตำแหน่งที่ต้องการเก็บงาน เช่นโฟลเดอร์ Documents แล้วพิมพ์:

```sh
mkdir greeting
cd greeting
npm init -y
npm install --save-dev typescript@6
```

`mkdir` สร้างโฟลเดอร์ ส่วน `cd` ย้ายตำแหน่งทำงานเข้าไปในโฟลเดอร์นั้น ทุกคำสั่งหลังจากนี้ให้รันจาก `greeting`

`npm init -y` สร้างไฟล์ `package.json` สำหรับบันทึกข้อมูลโปรเจกต์ ตัวเลือก `-y` ใช้ค่าเริ่มต้น การติดตั้ง TypeScript แบบ `--save-dev` ระบุว่าเป็นเครื่องมือสำหรับพัฒนา ไม่ใช่โค้ดที่ผู้ใช้โปรแกรมต้องโหลด

หลังติดตั้งจะมี `package-lock.json` และ `node_modules` เพิ่มขึ้น ไฟล์แรกบันทึกเวอร์ชันที่ติดตั้งจริง โฟลเดอร์หลังเก็บแพ็กเกจ ไม่ต้องแก้ไขไฟล์ในนั้น

## ตรวจความพร้อม

พิมพ์คำสั่งนี้ในโฟลเดอร์ `greeting`:

```sh
npx tsc --version
```

ควรเห็นข้อความขึ้นต้นด้วย `Version 6.` โดย `npx` เรียกเครื่องมือที่ติดตั้งไว้ในโปรเจกต์ และ `tsc` คือ compiler ที่แปลง TypeScript เป็น JavaScript

เปิดโฟลเดอร์ `greeting` ในโปรแกรมแก้ไขข้อความผ่านเมนู Open Folder ตอนนี้ยังไม่ต้องสร้างไฟล์โค้ด บทถัดไปจะพาพิมพ์ `index.ts` ทีละส่วน

:::note[ก่อนอ่านต่อ]
ตำแหน่งทำงานใน Terminal ต้องเป็นโฟลเดอร์เดียวกับที่เปิดในโปรแกรมแก้ไขข้อความ หากมีหลายหน้าต่าง ตรวจชื่อโฟลเดอร์ให้ตรงกันก่อนรันคำสั่ง
:::
