โปรเจกต์ช่วยให้ผู้อ่านเชื่อมแนวคิดจากหลายบทและตัดสินใจด้วยตัวเอง ตัวอย่างนี้ใช้โจทย์ขนาดเล็กเพื่อแสดงรูปแบบที่นำไปปรับใช้ได้

## โจทย์

สร้างโปรแกรม **Developer Greeting CLI** ที่รับชื่อและช่วงเวลาจากผู้ใช้ แล้วแสดงคำทักทายที่เหมาะสม

## ความต้องการ

- รับชื่อผู้ใช้จาก command line
- เลือกคำทักทายตามช่วงเวลา
- แยก logic ออกจากส่วนรับและแสดงผล
- มี test สำหรับกรณีหลักอย่างน้อยสามกรณี
- มี README อธิบายวิธีติดตั้งและเรียกใช้

## เกณฑ์ตรวจงาน

- โปรแกรมทำงานตรงตามโจทย์
- ชื่อฟังก์ชันและตัวแปรสื่อความหมาย
- จัดการ input ที่ไม่ถูกต้องได้
- โค้ดส่วนสำคัญมี test ครอบคลุม

เมื่อนำ Template ไปใช้ ให้เปลี่ยนโจทย์นี้เป็นโปรเจกต์ที่สรุปทักษะหลักของหนังสือคุณ
